# ガチャ見たよ帳

友達どうしで「どのお店にどのガチャがあったか」を投稿し合うWebアプリです。

- 見かけたガチャを投稿（シリーズ名・お店・エリア・状態・メモ）
- 「まだあった」「売り切れてた」で情報を更新
- 1週間以上更新のない投稿は薄く表示
- 「ほしいもの」キーワードに★（端末ごとに保存）
- **発売予定タブ**：気になる新作のシリーズ名・発売月（第○週）・メーカー・価格・公式URLを登録
  - 「今週から発売」「今月」「来月」…と時期ごとに自動で並び替え
  - 「♡ ほしい」でみんなの欲しいものを共有。今週発売の「ほしい」があるとタブに印が付く
  - 同じシリーズ名の「見かけた」報告を紐づけて、件数と最新の状態を表示

発売予定は手入力です。メーカー公式サイトはツールによる自動取得を禁止しているため（例：ガシャポン公式「サイトご利用条件」）、公式のスケジュールを見て気になるものだけ登録してください。画像や説明文の転載はしないでください。
- グループの**合言葉**が同じ人どうしで同じ帳面を共有

構成：HTML / CSS / JavaScript だけ（ビルド不要）＋ Firebase（Firestore・匿名ログイン）。GitHub Pages で公開できます。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目 |
| `app.js` | 動き（投稿・一覧・絞り込み・Firebase接続） |
| `firebase-config.js` | Firebaseの設定（空欄ならデモモード） |
| `firestore.rules` | データベースのアクセスルール |

## まず手元で動かす（デモモード）

`firebase-config.js` が空欄のままだと、投稿はそのブラウザにだけ保存されるデモモードで動きます。

```sh
cd このフォルダ
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます（`index.html` を直接ダブルクリックするとモジュールが読み込めないので、サーバー経由で開いてください）。

## 友達と共有できるようにする

1. **Firebaseプロジェクトを作る**
   [Firebase コンソール](https://console.firebase.google.com/) →「プロジェクトを追加」。Googleアナリティクスはオフでも大丈夫です。
2. **Webアプリを登録して設定を貼る**
   プロジェクトの設定 →「アプリを追加」→ Web（`</>`）。表示された `firebaseConfig` の中身を `firebase-config.js` に貼り付けます。
3. **匿名ログインを有効にする**
   Authentication →「始める」→ ログイン方法 →「匿名」を有効化。
4. **Firestore を作る**
   Firestore Database →「データベースを作成」→ ロケーションは `asia-northeast1`（東京）→ 本番環境モードで作成。
5. **ルールを貼る**
   Firestore →「ルール」タブに `firestore.rules` の中身を貼って「公開」。
6. **GitHub Pages で公開**
   GitHubにpush → リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存。数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。
7. **承認済みドメインを追加**
   Firebase の Authentication → 設定 → 承認済みドメイン に `<ユーザー名>.github.io` を追加。

## 使い方

- 最初にニックネームと合言葉を入れます。友達も同じ合言葉を入れると、同じ帳面を見られます。
- 画面下の「招待リンクをコピー」で、合言葉入りのリンクを友達に送れます（合言葉が入っているので、仲間内だけで共有してください）。

## プライバシーについて

- 合言葉はそのまま保存されず、ハッシュ化した値が部屋IDになります。合言葉を知らない人は投稿を読めません。
- ログインは匿名なので、メールアドレスなどは使いません。表示名はニックネームだけです。
- 推測されやすい合言葉（`gacha` など）は避けてください。
